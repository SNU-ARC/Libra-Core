# Libra-Core

[SGLang](https://github.com/sgl-project/sglang) v0.4.10 with **Libra** (ICLR 2026) and the baselines used in its prefill-throughput experiments.

This repository is a submodule of [SNU-ARC/Libra](https://github.com/SNU-ARC/Libra).
See the [README](https://github.com/SNU-ARC/Libra#readme) there for installation, and [REPRODUCE.md](https://github.com/SNU-ARC/Libra/blob/main/REPRODUCE.md) for reproducing the paper.

| Branch | Contents |
|---|---|
| `iclr2026_libra` | Libra, and the SGLang and EPLB baselines |
| `iclr2026_lina` (this branch) | Lina baseline |

Libra is built on SGLang v0.4.10 and released under the Apache License 2.0 (see [LICENSE](LICENSE)).
